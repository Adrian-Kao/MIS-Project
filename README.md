# 永安秘境探索｜Yongan Secret Adventure

**跟著小小探險家，跳進永安的故事裡！**

一款結合地方文化、互動地圖與故事導覽的探索式網頁。騎上蚱蜢、穿梭永安秘境，在每一次探索中，發現隱藏於山林與村落之間的故事。

---

##  專案介紹｜About the Project

**永安秘境探索（Yongan Secret Adventure）** 是一個以台灣永安地區為主題的互動式探索網站，透過遊戲化的方式，帶領使用者認識地方景點、自然景觀及人文故事。

不同於傳統的旅遊介紹網站，本專案將地圖探索、角色移動、動畫互動與故事敘事結合，讓使用者化身小小探險家，騎著蚱蜢在地圖中尋找景點，逐步解鎖各地的特色故事。

我們希望透過輕鬆、有趣且富有童話感的互動設計，讓地方文化不再只是靜態的文字介紹，而是一段可以親自參與的探索旅程。

**Explore, Discover, and Uncover the Stories of Yongan.**

## 核心特色｜Features

### 互動式地圖探索

以手繪風格的永安地圖作為遊戲場景。使用者可以自由操控角色移動，或點擊景點，讓角色前往目的地。

### 可愛的蚱蜢探險家

玩家操控騎著蚱蜢的角色，在地圖中移動與跳躍，搭配動作動畫及音效，營造輕鬆活潑的探索體驗。

### 景點解鎖機制

當探險家抵達指定景點，系統會觸發解鎖動畫並顯示景點名稱，接著展開對應的故事卷軸。

### 沉浸式故事卷軸

以童話卷軸的形式呈現地方故事。使用者能夠透過滑鼠滾輪或捲動條閱讀內容，逐步認識永安的特色與歷史記憶。

### 故事語音導覽

部分景點提供語音朗讀功能，讓使用者不只能閱讀故事，也能透過聲音感受地方文化。

### 箱收藏動畫

當使用者結束閱讀，故事卷軸會收回寶箱，透過動畫呈現完成探索的回饋效果。

## 如何遊玩｜How to Play

網站部署完成後，使用者只需要透過瀏覽器開啟連結，即可進入探索世界，不需要安裝任何應用程式。

**探索流程**

1. 進入永安秘境探索網站。
2. 在地圖中選擇想要探索的景點。
3. 操控蚱蜢探險家前往目的地。
4. 抵達景點後，觸發景點解鎖動畫。
5. 閱讀故事卷軸，或聆聽語音導覽。
6. 關閉卷軸，返回地圖繼續探索。

**操作說明**

| 操作方式 | 功能 |
|---|---|
| 滑鼠點擊景點 | 讓角色前往指定地點 |
| 方向鍵 ↑ ↓ ← → | 控制角色移動 |
| 按住滑鼠 | 加快角色移動速度 |
| 滑鼠滾輪 | 捲動故事內容 |
| 語音播放按鈕 | 播放或暫停景點語音 |
| B 鍵 | 關閉卷軸並返回地圖 |

## 技術架構｜Tech Stack

本專案採用純前端技術開發，以 Canvas 繪製互動場景，不需要後端伺服器或資料庫。

| 技術 | 應用 |
|---|---|
| HTML5 | 網站基本結構 |
| CSS3 | 網頁樣式與畫面配置 |
| JavaScript | 互動邏輯與角色控制 |
| p5.js | 2D 圖形繪製及動畫 |
| p5.sound | 跳躍音效與故事語音 |
| GitHub Pages | 靜態網站部署規劃 |
